FIRST-TIME SETUP

ตั้งค่า Project Tracker กับ Supabase ของคุณ

ใช้เพียง Supabase Project ใหม่ของคุณเอง ไม่ต้องใช้ฐานข้อมูลของผู้สร้าง Template

← กลับหน้า Tracker

1. Clone หรือ Use this template

นำ Repository ไปไว้ใน GitHub ของตัวเอง หรือ Clone ลงเครื่อง จากนั้นเปิดไฟล์ทั้งหมดใน VS Code

เปิด Repository ต้นฉบับ

2. สร้าง Supabase Project ใหม่

ไปที่ Supabase Dashboard เลือก New project แล้วเข้า SQL Editor

เปิดไฟล์ supabase/SETUP.sql คัดลอก SQL ทั้งหมดไปรันใน Project ใหม่ เพียงครั้งเดียว เพื่อสร้างตารางและ Private Storage Bucket

3. ใส่ค่า Supabase ของคุณใน config.js

จาก Supabase คัดลอก Project URL และ Publishable Key แล้วเปลี่ยนในไฟล์ config.js:

window.TRACKER_CONFIG = Object.freeze({
  SUPABASE_URL: "https://YOUR-PROJECT.supabase.co",
  SUPABASE_PUBLISHABLE_KEY: "sb_publishable_YOUR_PUBLIC_KEY"
});

ห้าม ใส่ Secret Key, service_role หรือ Database Password ลงไฟล์หน้าเว็บ

4. สร้างบัญชี Editor คนแรก

กลับหน้า Tracker แล้วกด สมัครบัญชี ด้วยอีเมลและรหัสผ่าน ยืนยันอีเมลหาก Supabase กำหนด หลังจากนั้นเจ้าของ Supabase ไปที่ SQL Editor แล้วรัน:

insert into public.tracker_editors (user_id)
select id from auth.users
where lower(email)=lower('YOUR_EMAIL@example.com')
on conflict (user_id) do nothing;

แก้ YOUR_EMAIL@example.com เป็นอีเมลจริงของคุณ แล้วเข้าสู่ระบบอีกครั้ง จะได้รับสิทธิ์ Editor

5. เริ่มสร้างโครงการและ Deploy เอง

กรอกชื่อโครงการ จำนวนสัปดาห์ และรายการข้อใหม่ได้ทันที โครงการเริ่มต้นเป็นข้อมูลว่าง ไม่มีข้อมูล CoopConnect

เมื่อทดสอบเสร็จ Push Repository และเปิด Settings → Pages ใน GitHub เพื่อเผยแพร่เว็บของตัวเอง ตั้ง Supabase Auth Site URL / Redirect URLs ให้ตรงเว็บไซต์

สำคัญ: รายการโครงการ/งาน/โน้ตเป็นข้อมูลสาธารณะ ส่วนภาพหลักฐานต้องล็อกอินก่อนจึงดูได้

ดูรายละเอียดทุกขั้นตอนและการแก้ปัญหาได้ในไฟล์ SETUP.md
